# Черновая модель в SketchUp

`denli_draft.rb` принимает экспорт `denli-project/1` с `input`, `plan`, `quote`, `references`. Размеры входа в миллиметрах. Перед импортом проверяются схема, числовые диапазоны и выход модулей за стену; изменение модели объединено в одну операцию Undo. Существующая модель не очищается.

1. В SketchUp Desktop откройте Ruby Console.
2. Выполните `load '/полный/путь/denli_draft.rb'` с фактическим путём на этой машине.
3. В меню Extensions выберите **Import DENLI draft JSON** и JSON, экспортированный из прототипа. Либо вызовите `DenliDraft.import_file('/путь/project.json')` в консоли.
4. Проверьте соответствие модулей плану, размеры в миллиметрах, количество и повороты; затем Undo должен удалить весь импорт одним действием.

Создаются обычные компоненты: боковины, дно и царги базовых корпусов, верх верхних корпусов, отдельные открытые полки. Сложные угловые/высокие модули и вытяжка представлены габаритами; фасады посудомойки и доборы являются заглушками. Внутренние механизмы, фасады корпусов, присадка, кромки, вентиляционные зазоры и крепление задних стенок не решены. Остров вынесен отдельно, поскольку контракт не содержит его положения. Стены предполагаются ортогональными.

Атрибуты лежат в словаре `denli_draft_v1`; связь с `quote.parts` сохраняется по модулю Н/В/П. Она является ссылкой для сверки, не гарантией соответствия каждой 2D-детали 3D-геометрии. Габаритные панели не должны попадать в производственный список. Настоящих Dynamic Components с формулами здесь нет; изменение атрибута не перестраивает геометрию, нужно изменить план и импортировать заново.

Полный запуск в SketchUp пока не выполнен: в текущем окружении нет SketchUp Desktop. Следовательно, работоспособность в приложении и производственная пригодность не подтверждены. 13 ноября 2026 года синтаксис проверен парсером Tree-sitter Ruby без ошибок; это не `ruby -c` и не запуск SketchUp. CSV разобран стандартным CSV-парсером: 10 колонок и одна тестовая деталь.

## Пример CSV VIYAR

`viyar-import-example.csv` иллюстрирует документированные колонки одного прямоугольного тестового элемента. Материал и толщину выбирают в импортере. Индекс кромки 1 по умолчанию означает 0,5 мм, 2 означает 2 мм, если иной материал не выбран в списке; 0 означает отсутствие кромки. Текстура `+` учитывается по длине. Для примера заданы пильные размеры 500 × 300 мм, количество 1 и кромка только по верхней стороне.

Этот файл НЕ выгружен из модели и НЕ проверен импортом в аккаунте VIYAR. До использования сверить ориентацию сторон, настройки размеров, выбранный SKU кромки и фактический результат. Формат не передаёт сверления и фигурные обработки. [Официальный формат](https://www.viyar.pro/service/doc/?cid=dsp&s=details-import)
