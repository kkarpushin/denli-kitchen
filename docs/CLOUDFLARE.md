# Cloudflare Pages

Основной адрес: https://denli-kitchen.pages.dev/

Проект Pages: `denli-kitchen`; production-ветка: `main`. Сайт открывается без входа в ChatGPT. Доступ к репозиторию GitHub настраивается отдельно. Фото по-прежнему обрабатываются только в браузере.

## Повторная публикация

Используется Direct Upload через Wrangler. Изменения в GitHub сами по себе не публикуются. Нужны Node.js 22+ и доступ к этому проекту в Cloudflare.

После входа через `npx wrangler@4 login` или настройки `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID` в окружении:

```bash
npm test
npm run build
npx wrangler@4 pages deploy dist --project-name denli-kitchen --branch main
```

При доступе к нескольким аккаунтам задайте `CLOUDFLARE_ACCOUNT_ID` нужного аккаунта. Ключи в репозиторий не добавляются. Правила доступа к исходникам и аккаунту Cloudflare настраиваются отдельно.

Сборка очищает `dist` и помещает туда только `index.html`, три ES-модуля и изображения из `assets`. Не загружайте корень репозитория: исследование, адаптер SketchUp, документация и результаты QA входят в комплект команды, а не в публичный сайт.

## Проверка публикации

Откройте основной адрес в новой вкладке без авторизации. Пройдите путь «Спробувати на прикладі» → оценка размеров → стандартный стиль → предложение; сохраните JSON и PDF. Проверьте мобильную разметку и отсутствие ошибок загрузки ES-модулей. Для повторяемых браузерных проверок установите `DENLI_TEST_URL=https://denli-kitchen.pages.dev` и запустите QA-скрипты из README.

Для отката можно повторно опубликовать сборку нужного коммита в тот же проект. Прежняя приватная копия в Sites сохранена отдельно; публикация на Pages её не обновляет.

[Документация Cloudflare Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/).
