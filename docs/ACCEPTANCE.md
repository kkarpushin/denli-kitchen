# DENLI — следующий этап для команды

Пакет содержит рабочий прототип, авторский каталог и технические черновики. Сначала воспроизведите сценарий, затем проверяйте производственные переходы по одному.

## 1. Воспроизвести прототип

- Разработчик запускает приложение и 12 Node-проверок.
- Проходит прямую, угловую и П-образную кухни, сохраняет JSON и PDF.
- Проверяет, что смета сходится, невозможные размеры отклоняются, фото не уходят на сервер.
- Читает полный артефакт `HANDOFF.html` и исследование с первичными источниками.

## 2. Проверить каталог

Конструктор проверяет геометрию корпусов, технологические зазоры, размещение техники, угловые и высокие модули, фасады, крепления, кромку и обработку. У каждого утверждённого модуля должны быть версия, артикул/идентификатор, диапазоны параметров и контрольный образец. Черновик нельзя помечать утверждённым только по прохождению программных тестов.

## 3. Замкнуть один производственный пример

На лицензированной рабочей станции SketchUp импортировать `examples/straight.json`, проверить миллиметры, раскладку, количество и Undo. Сопоставить геометрию с деталировкой; текущий адаптер не гарантирует этого. Затем проверить одну прямоугольную деталь после импорта VIYAR: материал, толщина, текстура, четыре кромки, размеры и цена. Дальше расширять до полного проекта с присадкой и фигурными операциями. Успешная загрузка файла сама по себе не является сверкой.

Публичный документированный API VIYAR не подтверждён. Первый путь — документированный файловый импорт и расчёт в авторизованном аккаунте; возможный партнёрский API проверяется по документации поставщика.

## 4. Проверить измерения и деньги отдельно

Собрать реальные фотографии с контрольными замерами; разделить настройку и отложенную проверку. Сравнивать эталонную геометрию, нейросетевые кандидаты и при необходимости многовидовой/LiDAR путь. Для модели оценивать реальную погрешность и долю отказов, а не только внутреннюю confidence.

Для цены сравнивать одинаковую комплектацию, актуальные закупки, доставку, монтаж и налоги. Отчёт должен показывать число проектов, медиану, 95-й процентиль, максимум ошибки, долю в ±5% и долю ручного разбора. Средняя ошибка 5% не подтверждает требование «максимум 5%».

## 5. Подготовить коммерческий сервис

Перенести каталог/расчёт на сервер, добавить версии проектов, обработку ошибок и повторов, хранение и удаление фото, согласованную политику данных, генерацию визуализаций и подтверждение заявки. Обозначить этап, на котором человек утверждает производственный заказ. Для фотопровайдеров и моделей выбрать и проверить лицензии. До этого продукт остаётся демонстрационным прототипом.
