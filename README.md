# DENLI Kitchen

Рабочий прототип кухни по фото и технический комплект для команды: собственный стартовый каталог, расчётная модель, исследование замеров, патенты и черновой адаптер SketchUp.

**Начать с [артефакта HANDOFF.html](HANDOFF.html)** — после запуска откройте [локальную страницу передачи](http://127.0.0.1:8765/HANDOFF.html). Она объединяет описание проекта, полное исследование и план интеграции.

[Приватный онлайн-прототип владельца](https://denli-kitchen-prototype.karpushin750463.chatgpt.site) требует его доступа. Доступ к этому GitHub-репозиторию автоматически не открывает онлайн-прототип; локальная версия запускается самостоятельно.

## Запуск за минуту

Нужен Node.js 22 или новее. Для самого приложения нет npm-зависимостей, API-ключей или платных сервисов.

```bash
git clone https://github.com/kkarpushin/denli-kitchen.git
cd denli-kitchen
npm start
```

Открыть http://127.0.0.1:8765 . Для первого прохода выбрать планировку, на шаге помещения нажать «Спробувати на прикладі» для каждой стены и пройти остальные шаги. Не открывайте `index.html` через `file://`: браузер ограничивает загрузку ES-модулей.

## Что работает

Фото/ручные размеры → выбор стиля, материалов и техники → проверка модулей → эскиз → демонстрационная смета → PDF/печать и JSON проекта. Поддерживаются прямая, угловая и П-образная кухни. Ссылка или картинка-референс сохраняется как пожелание, без автоматического анализа. Фото обрабатываются в браузере и не отправляются; в экспортированный JSON они не включены.

Каталог, правила и ставки придуманы как стартовая модель по заданию владельца. Это не действующий прайс DENLI. Изображения показывают сгенерированные примеры стилей, а не рендер загруженной фотографии или рассчитанной схемы. Проект не отправляет заявки, SMS, заказы и платежи.

## Разработка и проверка

```bash
npm test
npm run build
npm run examples
```

`npm test`: 14 проверок геометрии и расчётов, включая 150 преобразований изображений и 480 комбинаций планировки и 72 сочетаний высоты, планировки и стиля. `npm run build` собирает `dist/` из явного списка файлов; документы, исходные картинки и QA туда не входят. Изменения не развёртываются автоматически.

Для браузерных тестов нужны Python 3.10+ и Playwright. При необходимости создайте отдельное виртуальное окружение:

```bash
python3 -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
# npm start должен работать в другом терминале
python qa/browser_test.py
python qa/browser_provenance.py
python qa/browser_focusgroup.py
python qa/browser_photo_editor.py
```

Результаты появляются в `qa/results/current/`. `DENLI_TEST_URL`, `DENLI_CHROME` и `DENLI_QA_OUT` переопределяют адрес, путь Chromium и каталог результатов. На Linux системные библиотеки Chromium при необходимости устанавливаются штатным `python -m playwright install --with-deps chromium`.

Исходный браузерный сценарий проверен на ширинах 1440, 768, 390 и 320 px, включая JSON/CSV, печать/PDF и происхождение размеров. Синтетические проверки не доказывают точность замера реальной кухни или цены.

## До использования в производстве

Оценка по фото предполагает видимую плоскую прямоугольную стену и известный эталон в той же плоскости. Она не измеряет скрытую геометрию, кривизну, коммуникации и монтажные допуски. Чувствительность к расстановке точек не является гарантией точности.

Реальные SketchUp и VIYAR здесь ещё не соединены. Ruby-адаптер создаёт черновые обычные компоненты без Dynamic Component формул; он не испытан в SketchUp Desktop. Браузерный CSV — черновая таблица, а не подтверждённый производственный импорт. Цель ±5% сметы требует проверки на отложенных реальных проектах.

Правила и цены находятся в клиентском JS; для коммерческого сервиса библиотеку и расчёт нужно перенести на сервер. Исследовательские модели не включены в комплект, их веса и лицензии проверяются отдельно. Исходные картинки не являются фотографиями выполненных заказов DENLI.

## Передача доступа

Владелец добавляет участников через GitHub Settings → Collaborators либо позже передаёт репозиторий выбранной организации. Репозиторий остаётся приватным; никаких приглашений этот комплект не отправляет. Команде достаточно доступа к репозиторию и инструкции выше.
